# mcp/seq-otlp

Standalone MCP server container that connects AI agents to an existing Datalust Seq instance.

## What This Image Does

- Exposes a Model Context Protocol (MCP) server over stdio.
- Connects to Seq using `SEQ_URL` and `SEQ_API_KEY`.
- Supports agent guidance, starter tools, and full Seq API route coverage through generated MCP tools.

## Agent Entry Points

- `seq_agent_guide` - tool selection rules, recommended workflows, example calls, and safety limits.
- `seq_connection_test` - connectivity, authentication, API base URL, and health URL validation.
- `seq_starter_overview` - safe read-only summary of API root, current user, diagnostics, signals, and workspaces.
- `seq_starter_events_search` - bounded event/log search by filter, signal, time range, count, and render mode.
- `seq_starter_data_query` - bounded Seq `q` queries and aggregations.
- `seq_api_catalog` then `seq_api_request` - advanced official Seq API route access.

## Required Environment Variables

- `SEQ_URL` - Seq base URL (recommended) or API URL
- `SEQ_API_KEY` - Seq API key

Examples of supported URL formats:

- `http://host.docker.internal:10150`
- `http://host.docker.internal:10150/api`
- `https://seq.example.com`
- `https://seq.example.com/api`

## Quick Run

```bash
docker run --rm -i \
  -e SEQ_URL=http://host.docker.internal:10150 \
  -e SEQ_API_KEY=your-key \
    mcp/seq-otlp:latest
```

## Container Lifecycle

The MCP client owns this stdio server's lifetime. The server exits when the
client closes stdin and shuts down gracefully on `SIGTERM` or `SIGINT`.
Launch it with both `-i` and `--rm`: `-i` carries MCP stdio traffic, while
`--rm` tells Docker to remove the container after the process exits.

Do not launch this stdio server detached with an indefinitely open stdin. If a
running instance remains after use, the launcher must close stdin or stop it. If
an exited instance remains, the launcher omitted `--rm`. Container removal is a
host responsibility; the image does not receive Docker-socket access and cannot
safely remove itself.

## MCP Client Example

```json
{
    "mcpServers": {
        "seq-otlp": {
            "type": "stdio",
            "command": "docker",
            "args": [
                "run",
                "--rm",
                "-i",
                "-e",
                "SEQ_URL=https://seq.example.com",
                "-e",
                "SEQ_API_KEY=<YOUR_SEQ_API_KEY>",
                "mcp/seq-otlp:latest"
            ]
        }
    }
}
```

## Permissions

For read/query scenarios, use a least-privilege API key with `Read` permission.

Additional permissions (`Write`, `Project`, `Organization`, `System`, `Ingest`) are only required when invoking endpoints that demand them.
